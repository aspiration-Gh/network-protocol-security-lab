## 怎么用

- **第一次通读**：按 01 → 02 → 03 → 04 → 05 顺序，每章先看「本章知识地图」那张表，再看小节。
- **考前冲刺**：先读 00 的 0.6（七类攻击族）、0.7（防御总表）、0.8（必背数字），再回各章「考点提示」。
- **被问到"某个攻击属于哪一层"**：查 00 的 0.6 表；被问到"怎么防"：查 00 的 0.7 表。
- **每章末尾**的「易错点与自测」含对比表 + 自测题（答案写在 `**答**：` 后），可遮住答案自测。

## 全课主线（一句话版）

协议设计时优先考虑"能通"，安全属性（认证、完整性、机密性）是后来补的；每一层的补丁方式不同，因此攻击面也不同：

| 层 | 先天缺失 | 典型攻击 | 主流补救 |
|---|---|---|---|
| 接口层 | 无源认证、共享广播域、交换机自学习可被污染 | MAC 泛洪、中间人、PPPoE 会话劫持 | 端口安全、CHAP 认证、隔离 |
| 网络层 | 源地址不可信、无分片策略约束 | IP 欺骗、源路由、分片攻击、ARP/DNS 欺骗、ICMP 重定向 | uRPF、ACL、IPSec、SAVI |
| 传输层 | 连接状态靠首部字段推断、ISN 可预测 | SYN 泛洪、RST 注入、会话劫持、反射放大 | SYN Cookie、随机 ISN、TLS |
| 应用层 | 认证与加密多为后加 | DNS 缓存投毒、HTTP 劫持、DHCP  starvation、明文口令 | DNSSEC/DoT/DoH、HSTS、PGP/SSH |

## 已知偏差与处理说明

1. **纯图片页**：PPT 中若干页只有标题和截图（如 AH/ESP 首部、LCP/CHAP 报文、PPP 帧格式、DHCP 选项、DNS 报文位图）。笔记按通行标准以表格重建，并在正文用 `> 补充：` 或说明块标注"原页为图示"。
2. **PPT 印刷错误**：第四章端口表把 Oracle 写作 1524（标准 1521），第四章笔记照 PPT 保留原值；00 速览采用 1521。第三章 ICMP 类型页（Slide 48/49）对 code 3 的解释自相矛盾，笔记以编码表为准并标注。
3. **2^48 地址数量**：PPT 写"约 7 万亿个"，与 2^48 量级不符，笔记只写"48 位空间远未耗尽"，未复制该数字。
4. **SSL 密钥长度**：PPT 一处写"主控密钥 48 位"，第四章统一为 48 字节并加注。
